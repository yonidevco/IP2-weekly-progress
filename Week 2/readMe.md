# Registration Form PHP Program

## Overview  
This program is a simple PHP script that processes a user registration form.  
It collects user information such as name, email, password, gender, and an optional profile picture.
The program validates the user input before processing the data.  
If there are validation errors, they are displayed to the user.  
If the input is valid, a success message is shown along with the submitted user information.

### It covers the concepts of
- Form handling with POST method
- Input validation
- Arrays
- PHP built-in functions such as filter_var(), htmlspecialchar(), trim() for validating and sanitizing inputs and
- File input handling with $_FILES
